### Resource-admission update (2026-10-23)

The Resource Governor now receives interval-based system CPU utilization derived from portable `os.cpus().times` counters. On measured CPU saturation (at least 90%), new task admission is reduced to half the configured task capacity, with a minimum of one; existing memory-pressure handling remains in force. CPU saturation is not mislabeled as memory pressure. The first CPU sample waits for a complete telemetry interval to avoid noisy startup readings. The existing resource tooltip shows the CPU sample and omits load average on Windows, where Node reports zero load average. Controlled macOS tests cover arithmetic, sampling, admission, API projection, and Windows-shaped display data. This is not Windows runtime acceptance or a representative application CPU/RAM benchmark; managed child-process tree RSS and idle/active/soak resource measurements remain open.
